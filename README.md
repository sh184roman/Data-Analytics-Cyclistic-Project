# Data-Analytics-Cyclistic-Project

This project is a data analytics case study based on Cyclistic, a Chicago-based bike-sharing company. The objective is to analyze and compare ride behavior between casual riders and annual members in order to generate insights that support business and marketing decision-making.

The project demonstrates an end-to-end data analytics workflow, including data cleaning, transformation, exploratory data analysis, and insight generation. Key patterns related to ride duration, frequency, and time-based usage were identified to inform strategies aimed at increasing annual memberships.

Data Source: Public Cyclistic (Divvy) bike-share datasets
Tools & Skills: Python (Pandas, NumPy), Data Cleaning, EDA, Data Visualization
Outcome: Actionable insights to support data-driven marketing and membership growth strategies
